# MedSpatial AI — Production Backend Dependencies
# =================================================
# These are the ONLY packages compiled into the Nuitka executable.
# PyTorch is EXCLUDED from runtime. The three models that actually use PyTorch
# tensors at inference time have been replaced:
#
#   anomaly_service.py  → OnnxInferenceEngine (onnxruntime)
#   chat_service.py     → ChatServiceProd (ONNX Q&A encoder, no torch)
#   layer_dissector.py  → uses threshold_decomposition() only (no refinement net)
#   explainability.py   → only reasoning chains + synthetic heatmaps (no torch hooks)
#
# Modules that still import torch at MODULE LEVEL (not just runtime):
#   anomaly_graph.py    → imported only for DISEASE_LABELS constant by explain.py
#   depth_lifter.py     → called only from reconstruct_from_xray() which is X-ray path
#   medical_qa.py       → imported by chat_service.py
#
# These are handled by the monkey-patches in main_prod.py:
#   sys.modules["app.services.anomaly_service"] is replaced with the ONNX shim.
#   ChatService is replaced with ChatServiceProd (no torch import).
#   LayerDissector.decompose() has use_refinement=False set by default in prod.
#
# Approximate installed sizes:
#   onnxruntime==1.17.0            ~12 MB
#   numpy==1.26.3                  ~15 MB
#   scipy==1.12.0                  ~45 MB
#   scikit-image==0.22.0           ~25 MB
#   fastapi + uvicorn + starlette  ~8  MB
#   pydicom + pylibjpeg            ~6  MB
#   trimesh + rtree                ~12 MB
#   reportlab + python-docx        ~8  MB
#   SQLAlchemy + aiosqlite         ~5  MB
#   transformers + tokenizers      ~30 MB  (tokenizer only, no torch model)
#   sentence-transformers          ~5  MB  (ONNX backend via optimum)
#   matplotlib                     ~35 MB  (required by report_service._render_slices)
#   Pillow                         ~4  MB
#   others                         ~15 MB
#   ─────────────────────────────────────
#   Total (uncompressed)           ~225 MB
#   After Nuitka onefile           ~120-160 MB (zstandard compression)
#
# To install on build machine:
#   pip install -r requirements_prod.txt
